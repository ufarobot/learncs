## Муниципальный этап: федеральные рекомендации 2026/27

В рекомендациях ЦПМК по школьному и муниципальному этапам указаны C++ и Python. В проверенных пунктах конкретные версии не заданы; список средств формирует предметно-методическая комиссия.

В приложении среди сред разработки перечислены **Code::Blocks, Visual Studio Community, VS Code, PyCharm, CLion и Wing IDE**. Это примеры инструментов в федеральном документе, а не подтверждение установки в Татарстане.

Источник: [методические рекомендации 2026/27](https://vso.edsoo.ru/public.php/dav/files/ywgpTXZJfX4RWE2/?accept=zip), утверждены ЦПМК 24 июня 2026 года, протокол № 3. С.29, п.1.3.3.1; с.34, п.1.3.3.7; приложение 2, с.138–139. Ссылка открывает официальный комплект файлов.

## Региональный этап: последний подтверждённый федеральный ориентир

На [федеральной странице регионального этапа](https://vserosolimp.edsoo.ru/region_way) при проверке найдены требования **2025/26**. Требования 2026/27 там не найдены. В таблице ниже именно прошлый сезон и минимальные версии; более новые версии допускаются.

| Язык | Компилятор или интерпретатор | Среды разработки в требованиях 2025/26 |
| --- | --- | --- |
| C++ | GNU C++ / MinGW 9.3.0+; альтернативно MS Visual C++ Community 2017+. Должен быть доступен хотя бы один режим C++17 или новее | Code::Blocks 20.03+, VS Code с расширением `ms-vscode.cpptools`, встроенная среда Visual Studio |
| Python | Python 3.10+ | IDLE, Wing IDE, PyCharm Community 2019.1+, VS Code с расширением `ms-python.python` |

Источник: [общий сборник требований регионального этапа 2025/26](https://vso.edsoo.ru/public.php/dav/files/RZxQ6HWzNqPFfoG/?accept=zip), Москва, 2025, 325 страниц. Профиль «Программирование»: пп.7.14–7.18, с.67–69; таблицы 1–2 на с.68, режим C++17 на с.69. По п.7.23 на с.70 доступные компиляторы и команды запуска должны быть указаны в памятке участника. Номера относятся к общему сборнику и совпадают с порядковыми страницами PDF.

Название **PyCharm Community** здесь сохранено так, как оно указано в документе. Современный единый PyCharm и отдельная открытая сборка — разные варианты распространения; наличие одного из них на площадке нужно уточнять у организаторов.

## Можно ли пользоваться CLion

CLion упомянут в федеральных рекомендациях школьного и муниципального этапов 2026/27. В проверенных таблицах требований регионального этапа 2025/26 он не упомянут. Само отсутствие названия не устанавливает запрет, но рассчитывать на установленный CLion без подтверждения площадки нельзя.

Для домашнего обучения JetBrains предоставляет **личную бесплатную некоммерческую лицензию**. Активация требует JetBrains Account и подключения к интернету; после неё возможна работа офлайн. [Условия и активация CLion](https://www.jetbrains.com/help/clion/register.html).

Для установки на компьютеры учебного класса предусмотрены отдельные **classroom licenses**, включающие CLion. Личная некоммерческая лицензия не предназначена для развёртывания класса. Возможность получить и активировать лицензию конкретной российской школой здесь не проверена. Учебная лицензия также не является подтверждением комплектации олимпиадной площадки. [FAQ JetBrains для учебных классов](https://www.jetbrains.com/help/classroom-licenses/faq.html).

## Что установить дома

Для первых занятий на Python можно воспользоваться нашей [инструкцией установки Python и PyCharm](/software/). В ней выбран Python 3.13.16 для домашней установки. Он соответствует минимуму Python 3.10+ в федеральных требованиях прошлого регионального сезона, но это не обещание той же версии на вашей олимпиаде.

Если преподаватель или организатор уже сообщил конкретную версию, ориентируйтесь на неё. Для C++ уточните три вещи: **компилятор и его версию, стандарт языка, доступную IDE**. До получения этих сведений нельзя составить точную инструкцию, совпадающую с рабочим местом участника в Татарстане.
