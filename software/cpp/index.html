Установка CLion

Скачайте и установите CLion для занятий на C++.

Инструкции: Java · C++ · Python.

1. Скачайте CLion

Выберите свой компьютер. Ссылки ведут на официальный сайт JetBrains. Если загрузка недоступна в вашей сети, попробуйте VPN.

КомпьютерCLion 2026.2.4
Windows, Intel или AMDСкачать
Mac, IntelСкачать
Mac, чип Apple M1, M2 и новееСкачать

На Mac тип процессора можно посмотреть в меню Apple → Об этом Mac.

2. Установите

Windows: откройте скачанный файл. Нажимайте Next, затем Install. Дождитесь окончания установки и нажмите Finish.

Mac: откройте скачанный файл и перетащите значок CLion в папку Applications («Программы»).

3. Откройте программу

Запустите CLion из меню «Пуск» в Windows или из папки «Программы» на Mac.

При первом запуске для домашних занятий выберите бесплатную лицензию Non-commercial use и войдите в аккаунт JetBrains.
