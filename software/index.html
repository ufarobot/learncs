Установка Python и PyCharm

Скачайте и установите Python и PyCharm для Windows или Mac.

Инструкции: Java · C++ · Python.

Выберите свой компьютер и скачайте обе программы.

КомпьютерPython 3.14.10PyCharm 2025.3
Windows, Intel или AMD (x64)Скачать PythonСкачать PyCharm
Mac с процессором IntelСкачать PythonСкачать PyCharm
Mac с чипом Apple, серия MСкачать PythonСкачать PyCharm

На Mac тип процессора можно посмотреть в меню Apple → Об этом Mac. Ссылки PyCharm ведут на зеркало, используемое в LearnCS. Платная подписка для занятий не нужна.

Windows

  1. Откройте скачанный установщик Python.
  2. Отметьте Add Python to PATH, нажмите Install Now и дождитесь завершения.
  3. Откройте установщик PyCharm. Следуйте шагам мастера, оставляя предложенные настройки.
  4. Запустите PyCharm из меню «Пуск».

Mac

  1. Откройте скачанный файл Python с расширением .pkg и пройдите шаги установки.
  2. В папке Программы → Python 3.14 откройте Install Certificates.command и дождитесь завершения.
  3. Откройте скачанный файл PyCharm с расширением .dmg и перетащите приложение в Applications.
  4. Запустите PyCharm из папки «Программы».
